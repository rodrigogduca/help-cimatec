# Help SENAI

Ferramentas acadêmicas para estudantes do **SENAI CIMATEC**.

🔗 **Site:** [rodrigogduca.github.io/help-senai](https://rodrigogduca.github.io/help-senai/)

## Ferramentas

- **Passei SENAI?** — Calcule sua média semestral (AV1 25%, AV2 25%, AV3 30%, EDAG 20%) e descubra a nota mínima para a final.
- **Calculadora de Faltas** — Descubra quantas faltas você ainda pode ter com base na carga horária da disciplina (presença mínima: 75%).
